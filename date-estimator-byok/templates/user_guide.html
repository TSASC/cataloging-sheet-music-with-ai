User Guide

Run locally, bring your own keys, and review the results before exporting.

Local Setup
  1. Install Python 3.11 or 3.12. Install Git if you want to clone the repository.
  2. Clone with git clone https://github.com/TSASC/cataloging-sheet-music-with-ai.git, or download a ZIP from that repository and extract it.
  3. Open a terminal in the repository's date-estimator-byok subfolder and run python3 run.py. For a Git clone, use cd cataloging-sheet-music-with-ai/date-estimator-byok. On Windows, use py -3.12 run.py if python3 is unavailable.
  4. The launcher prepares a virtual environment, installs dependencies, and opens the local app in your browser. No app account is required.

Keep the terminal open while working. Press Ctrl+C to stop. Run the same command to reopen the app.

To update a Git clone, stop the app and run git pull --ff-only, then restart. ZIP installations need a new ZIP; preserve local settings and results separately.

Bring Your Own API Keys

Date search and Excel estimation do not need a model API key. Image transcription does.

  1. Open Settings and save your own provider key.
  2. Select the active provider, click Use Selected Provider, then choose and save a model.
  3. Return to Image Transcription or Batch Transcription.

Providers include OpenAI, Anthropic, Google Gemini, Harvard OpenAI, and Harvard Gemini. Harvard endpoints require authorized access and share one Harvard key. Model Comparison uses the Harvard OpenAI and Harvard Gemini providers.

Saved keys are encrypted in the local server-side session, which expires after 30 days. They do not follow you to another computer. Protect the project folder and its local settings.

Privacy: transcription sends image content and prompts to the selected provider. Comparison sends them to each selected provider. Local operation is not a zero-data-retention guarantee. Provider retention, billing, and access policies apply; do not send sensitive images without permission.

Main Workflows

Date Search

Enter publisher, city, address, and plate-number clues. The estimator matches IMSLP publisher records and combines the available date ranges. Review the explanation and source links; estimates are not authoritative dates.

Excel Upload

Upload an .xlsx file containing City, Publisher name, Address, and Plate number columns. Preview results, review rows, and export simple, detailed, or cataloging spreadsheets.

Image Transcription

Upload an image or supply a local file path. Review the prompt, transcribe with your chosen provider, then check and edit the extracted bibliographic fields before saving.

Batch Transcription

Upload several images or select a local folder. Review the prompt, start a run, transcribe images, and add accepted rows to the run. Export CSV or XLSX before ending your work.

Model Comparison

Select images and Harvard models, run a comparison, and inspect the side-by-side output. Both providers receive the selected images and prompts and may incur charges.

Research Tools

Publisher Match, Name Similarity, Imprint Lookup, Address Lookup, Plate Tables, and Date Formulas help investigate the data behind an estimate.

Optional Microsoft Sources

Local uploads and folders work without Microsoft configuration. OneDrive and SharePoint require your own Microsoft OAuth application and tenant permissions.

Set MICROSOFT_CLIENT_ID, MICROSOFT_CLIENT_SECRET, and MICROSOFT_TENANT_ID in your local environment or .env. Start on a fixed port with PORT=5001 python3 run.py on Mac/Linux, or run set PORT=5001 then py -3.12 run.py in Windows Command Prompt. Register the matching callback http://127.0.0.1:5001/oauth/onedrive/callback.

Use Connect OneDrive or Connect Microsoft in the image source selector, review the requested permissions, and select a folder. SharePoint uses the same Microsoft connection. Microsoft sign-in is optional and is not an app account.

Do not bypass browser security warnings. Check your application configuration and redirect URI if connection fails.

File Paths and Troubleshooting

Mac: select a file or folder in Finder, hold Option, right-click, and choose Copy as Pathname. Windows: right-click in File Explorer and choose Copy as path. Remove surrounding quotes before pasting if needed.

No API key: save a key for the active provider in Settings. A key for a different provider will not authorize the request.

Provider error: check key validity, model access, quota, and the provider's service status. Review partial results before retrying a batch.

Microsoft unavailable: configure your own OAuth application or use local uploads instead.

Date lookup fails: verify your internet connection and the publisher spelling. Date estimation retrieves publisher data from IMSLP.

App will not start: confirm Python 3.11 or 3.12 is installed and inspect the terminal error. Dependency installation needs an internet connection.
